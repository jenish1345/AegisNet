# AegisNet

## Evidence-Grounded AI for Scam Network Intelligence

AegisNet connects suspicious scam messages, impersonation calls, financial transfers, devices, and mule accounts into an explainable campaign view.

It checks alternative explanations, verifies AI-generated claims against source records, and gives fraud-response teams safe next steps without taking automated enforcement actions.

> AegisNet provides an investigation lead, not a determination of guilt.
